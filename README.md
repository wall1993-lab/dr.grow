# Dr. Grow — História 6º Ano (Pré-História)

Este repositório contém a especificação inicial do aplicativo educativo estilo "Duolingo",
voltado para o 6º ano e alinhado à BNCC para o estudo da Pré-História.

## Conteúdo
- Trilha pedagógica (8 módulos)
- Mecânicas de jogo (lições de 5 minutos, estrelas e cartas)
- Sistema de cartas (personagens, ferramentas, monumentos)
- Painel do professor (indicadores, pódio, turma única com possibilidade de expansão)

Consulte o documento completo em `docs/blueprint.md`.
